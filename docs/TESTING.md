# Проверки

Запускайте из корня проекта:

```sh
python3 -m unittest discover -s tests -v
bash tests/test_upstream.sh
bash -n src/tend.sh src/server.sh src/ui.sh
sh -n install.sh
```

Python-тесты проверяют конфигурацию, команды и флаги, мастер через терминал, вывод прогресса, подготовку SSH и передачу параметров загрузчиком. Проверка upstream запускает генератор конфигурации ноды во временном каталоге.

Эти проверки не выполняют установку на VPS. Для проверки установки нужен отдельный сервер Ubuntu 24.04 с доменом и данными ноды из панели. Проверьте новое SSH-соединение, подтверждение таймеров, сертификат, контейнеры и соединение клиента через настроенный в панели inbound. После перезагрузки повторите проверку доступа и сервисов.
