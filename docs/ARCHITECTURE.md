# Устройство проекта

`install.sh` скачивает архив `TendVPN/node-install` и запускает `src/tend.sh install`. Источник можно изменить через `--repo OWNER/REPO` и `--ref REF` перед параметрами установки либо переменные `TEND_REPO` и `TEND_REF`.

`src/tend.sh` обрабатывает команды и конфигурацию. `src/ui.sh` содержит мастер и сообщения. `src/config.py` проверяет JSON и вычисляет списки блокировки с учётом доверенных сетей. `src/server.sh` устанавливает компоненты и настраивает SSH, firewall и systemd.

Каталог `src`, сторонние исходники и закреплённые версии копируются в `/opt/tend`. Команды `tend` и `tend-menu` запускают `/opt/tend/src/tend.sh`. Имена команд и каталоги данных сохранены для существующих серверов.

Интеграция Remnawave reverse proxy хранится в `vendor` со своей лицензией. Остальные компоненты загружаются по коммитам из `upstream-lock.json` в `/var/lib/tend/upstream`.

Настройки и секрет сохраняются в `/etc/tend/config.json` с правами 600. SSH и защита имеют таймеры отката; `tend confirm-ssh` подтверждает доступ из нового соединения. Установка требует root и Ubuntu 24.04.
